# Изменения по версиям

Нумерация: мелкие обновления меняют третью цифру (0.3.0 → 0.3.1), крупные — среднюю с обнулением третьей (0.3.1 → 0.4.0). Первую цифру без отдельного решения автора не менять.
Для каждого публикуемого обновления обязательно поднять номер, записать изменения здесь и создать выпуск GitHub с актуальной Windows-сборкой.
Версия задаётся в `project.godot` (`application/config/version`) и видна в главном меню; у каждой версии есть git-тег `vX.Y.Z`.

  твоего паса сыграл карту, можно ответить снова. Бой решается, когда обе стороны спасовали подряд.
- Сторона, которой сейчас нечем ходить, просто пропускает ход и может вернуться в обмен после карты соперника.
- Лимит — по-прежнему до 3 карт на бой; «Великий сброс» и «Кольца глубин» по своему тексту закрывают обмен своей стороне.
- ИИ учитывает, что на его карту соперник может ответить даже после паса. По симуляции 2400 матчей: карт в бою 3.5 → 3.8,
  стихии 45.8–52.5 % (было 42.0–51.9 %), камбэки 26.8 → 28.7 %, Мастер против Бойца 61 → 55 %.

**Надписи и подсказки**
- Надписи держатся дольше, если текст длинный, и пропускаются по Enter / Пробелу / клику (подпись «Enter / Пробел / клик — дальше»).
- Подсказки висят, пока их не закроешь («Ясно (Enter)»), и идут по очереди, не сменяя друг друга. Подсказка о броске
  закрывается сама после броска.
- Итог боя закрывается по Enter / Пробелу.
- Подсказки больше не мешают броску: оттяжку сферы можно вести и отпускать поверх подсказки и панелей.
