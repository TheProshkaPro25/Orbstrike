# Палитры поверх MToon

Эти варианты подготовлены tools/avatars/build_palette_shaders.py из закреплённого
addons/Godot-MToon-Shader (MIT, полный текст LICENSE сохранён рядом).
Сторонние исходники аддона не изменены. Генератор добавляет palette_enabled и
palette_color после применения исходных lit/shade цветов. Светлота текстуры,
альфа, пряди, складки, освещение и контур сохраняются. При выключенной палитре
сохраняются исходные цвета MToon. Тон кожи меняется отдельно умножением _Color/_ShadeColor.

Все варианты — обычные ресурсы проекта, подготавливаемые до меню. Геометрия и
текстуры общие, ShaderMaterial/next_pass локальны для каждого актёра. Материалы
сохраняются до frame_post_draw при смене/удалении модели, чтобы renderer успел
обработать зависимости. Изменения делайте в генераторе, затем пересоздайте файлы.

Точечные/прожекторные источники используют ATTENUATION как интенсивность один раз,
без pow(att,.1) и повторного художественного порога дальности. Это предотвращает
выбеливание аватаров сильными витражными источниками Святилища, сохраняя toon-нормали
и реальные тени. Адаптация назначается всем MToon-поверхностям, включая материалы
без перекраски; исходный addons/Godot-MToon-Shader остаётся неизменным.
