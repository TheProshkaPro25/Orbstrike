# Аниме-персонаж редактора

## Текущий редактор — готовая VRM-основа

В обычном меню уже используется VRM CharacterEditor: сохранение v2, независимые
причёски/костюмы, лицо, палитры и рост. Костюмы получили веса и подготовленные Skin;
VrmFighter используется в матчах с портретами и небольшими жестами.
Текущая подготовка/лицензии/границы —
assets/avatars/vrm/README.md. Старые разделы ниже описывают процедурный прототип,
сохранённый для сравнения; его образ больше не является основным редактором.


Текущий образ полностью переработан после отклонения предыдущих вариантов.
`anime_head.py` создаёт компактное лицо, глаза, веки/брови, уши и шею;
`anime_hair.py` — три причёски из цельных пересекающихся клиновидных прядей;
`anime_body.py` — руки, торс под одеждой, короткую куртку/воротник, майку,
наручи, пояс, брюки с карманами/наколенниками и высокие кроссовки.
Из MakeHuman оставлены только кисти с пальцами и 137-костный риг.
Исходные человеческие торс/голова, male_casualsuit01 и shoes01 больше не используются.

Есть три телосложения: сбалансированное, стройное и атлетичное. Два морфа
BodyLean/BodyAthletic согласованно меняют все девять частей тела/костюма/кистей;
голова и волосы сохраняют размер. FaceNarrow/FaceBroad меняют нижнюю часть лица.
Цвета кожи/волос/радужки/куртки/акцентов управляются локальными материалами.
Геометрия общая для актёров, обновления профиля не пересоздают GLB или меши.
Профиль v1 расширен необязательным `body`: старым файлам назначается 0,
существующие ID остальных полей не переставлялись. Пока это один фасон костюма.

## Воспроизведение

```bash
python tools/avatars/fetch_sources.py
BLENDER_USER_RESOURCES="$PWD/build/avatar-source/blender-user" XDG_CACHE_HOME="$PWD/build/avatar-source/cache" blender --background --factory-startup --python tools/avatars/build_mpfb_fighter.py
python tools/avatars/check_mpfb_asset.py
python tools/check.py --profile presentation --checks import character-editor
```

В sources.json закреплён SHA MPFB 2.0.18. Теперь нужен только этот архив:
пакеты system/hair01 больше не скачиваются и не участвуют в сборке.
Blender работает фоном с изолированными настройками в build/avatar-source/;
аддон не устанавливается в пользовательские настройки. В игре не нужны
Blender, Python и сеть. GLB прогревается до меню через StartupCatalog.

Выход — assets/avatars/fighter_mpfb.glb и manifest, рабочий .blend — в build.
Имя GLB сохранено для совместимости путей загрузки. 17 мешей, 137 костей,
внешних и встроенных изображений нет: рисованная радужка и блики — shader.
Лицензия кистей/рига: assets/avatars/LICENSE-MAKEHUMAN-CC0.md;
оригинальная геометрия проекта отделена от этих CC0-ресурсов в CREDITS.md.
MPFB GPLv3 используется только инструментом подготовки, его код не поставляется в игре.

Для прядей важен непрерывный базис: не переворачивать поперечную ось при
смене знака её X-компоненты — это давало самопересечение на изгибе.
В idle добавочные вращения умножаются на импортированную ориентацию костей.
Текущая привязка предназначена для предпросмотра/idle: полный набор боевых
движений и качество деформаций при больших сгибаниях не проверены.

Проверки запускаются только штатным свёрнутым нефокусируемым wrapper.
Свежие кадры смотрят спереди, в три четверти и сзади, включая волосы и тела.
Художественная приёмка пользователем отдельно от автоматических проверок.
Существа и их GLB в этой задаче не изменяются.


## Готовая VRM/MToon-основа

Готовая основа используется напрямую в «Мой персонаж».
Готовые модели/SHA/лицензии и ограничения — assets/avatars/vrm/README.md.
Проверить закреплённые данные: python tools/avatars/fetch_vrm_sources.py --verify.
Проверить UI: python tools/check.py --profile presentation --checks vrm-preview.
Код процедурного редактора сохранён как LegacyCharacterEditor для сравнения.
