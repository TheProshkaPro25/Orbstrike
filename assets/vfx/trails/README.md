# Стихийные шлейфы Orbstrike

Геометрия создаётся из последних точек физического полёта сферы.
Шейдер Orbstrike рисует жилы, светящиеся кромки и дымку процедурно.
Каждый стиль имеет собственный рисунок, палитру и ритм бликов.
В файлах эффекта используются только код и числовые параметры Orbstrike.

Визуальный ориентир — рендеры [Vefects Trails VFX 1.0.3](https://store.godotengine.org/asset/vefects/trails-vfx/).
Код, меши, текстуры, материалы, параметры сцен и звук пакета в
реализации шлейфов Orbstrike не использовались. Сравнение доступно
в [локальном стенде](../../../tools/vfx_showcase/README.md).

| Стихия | Стиль |
| --- | --- |
| Пламя | Fire · горячие клинья и тонкий красный след |
| Буря | Electric · ледяные иглы и кобальтовая дымка |
| Свет | Sound · пять золотых жил с бегущими бликами |
| Камень | Earth · охряные щепы и пылевая дуга |
| Тень | Dark · малиновые лезвия на винном фоне |
| Прилив | Water · плавные синие струи с перехлёстом |

Cosmos, Ice, Nature и Void доступны на стенде. Boot выделяет шесть
экземпляров для матча. В каждом одна сетка на 25 поперечных сечений и
кольцевой буфер истории. Активный след записывает центр оболочки из
физического цикла, а шейдер привязывает голову к её текущему положению
в момент отрисовки. В матче время жизни короче, чем на стенде, чтобы
полёт оставался читаемым в камере погони. При качении след сразу
скрывается и очищает историю.
