# Грифалон: принятый ручной комплект

Шесть сжатых `AnimationLibrary` (`fire/gale/stone/light/shadow/tide.res`), примерно
66 KB каждая. Astra medium создала ключи и адаптировала их к исходному rest каждого
варианта. Автор принял полный набор Света 8 ноября 2026. Это ручная анимация;
в этих ресурсах нет сгенерированного движения UniMate или зависимости от его весов.

Каждая библиотека содержит `idle` 2.4 с, `stance` 1.1 с, `roar` 1.1 с,
`attack` 1.2 с (контакт 0.4 с / 1/3), `hit` 0.8 с. По 63 канала TRS для исходных
21 костей, пути `Skeleton3D:<bone>`. Движение объекта принято́го GLB свернуто в
корневую кость с учётом исходного grounding; исходные GLB/rest/bind/UV/веса сохранены.

Для Бури добавлен отдельный `gale-wing-skin.res` (152485 bytes):9873 вершины правого крыла получают локальное перераспределение только wing.R/tip.R/fan.R. Consumer создаёт immutable mesh clone, сохраняет исходные raw geometry/attribute/index/LOD/material данные и чужие влияния; исходный PackedScene не меняется. Ресурс обязателен при Boot.

Все шесть библиотек имеют общий `master_motion_source_sha256`; metadata-only сохранение поменяло file SHA, но не ключи/интерполяцию/время. В новом комплекте `_tempo=1` для всех стихий, общий пользовательский BattleTempo сохранён.

`scenes/grifalon_motion.gd` читает ресурсы до меню, валидирует комплект и меняет
только пути к реальному Skeleton3D. Авторские значения/интерполяция не меняются.
Новый флаг отключает только этому комплекту legacy torso/tail/flight и добавочные
hover/lunge/recoil. Контакт, tempo, hitstop и события остаются общими. Метаданные
скелетно деформированной поверхности задают консервативную высоту/ширину для камеры.

Рецепт, SHA и ограничения: [runtime-отчёт](../../../docs/audits/2026-11-08-grifalon-fullset-runtime/README.md),
[ретаргет Astra](../../../build/experiments/unirig-unimate-2026-11-08/grifalon-retarget-six/README.md).
Обновление ключей/ретаргета требует отдельной версии и повторной приёмки; не
прогонять массовые старые rig/personality scripts и не менять production GLB.
