# Миниатюры редактора

`catalog_0.png` и `catalog_1.png` — изображения имеющихся частей гардероба на
двух игровых основах. Лицензии частей перечислены в `CREDITS.md` и соседних
папках `vrm`, `itch`, `street`, `sport` и `booth`.

Атлас Сакурады имеет размер 800×960, атлас Виты — 800×960. Пять столбцов,
ячейки 160×192. Первые одиннадцать ячеек — причёски в порядке `vrm_style`,
дальше ячейки `vrm_clothes` для костюмов Сакурады № 1–9 и № 12–14 и костюмов
Виты № 1–13. Ячейки выведенных № 10–11 Сакурады пусты.
Высокий хвост показан в три четверти, чтобы была видна собранная часть волос.
Миниатюры показывают исходные цвета, а текущая палитра видна на большом герое.
Статические PNG загружаются до меню; отдельных живых актёров на плитки нет.

Воспроизведение в свёрнутом нефокусируемом окне:

```sh
godot --path . --windowed --position -20000,-20000 --log-file /tmp/sfery-editor-thumbnails.log -s res://tools/avatars/build_editor_thumbnails.gd
```

После генерации выполнить обычный импорт проекта. Скрипт использует
`tools/test_window.gd` и не поднимает окно поверх рабочего стола. Параметр
`-- --booth-outfits` переснимает плитки BOOTH. `-- --vita-sport` обновляет
спортивную миниатюру Виты.
