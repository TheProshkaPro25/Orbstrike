# Миниатюры редактора

`catalog_0.png` и `catalog_1.png` — изображения имеющихся частей гардероба на
двух игровых основах. Новых сторонних ресурсов нет; лицензии исходных частей
перечислены в CREDITS.md и соседних папках vrm, itch, street.

Каждый атлас 800×768: пять столбцов, ячейки 160×192. Первые одиннадцать ячеек —
причёски в порядке vrm_style; следующие семь/восемь — костюмы vrm_clothes.
Высокий хвост показан в три четверти, чтобы была видна собранная часть волос.
Миниатюры показывают исходные цвета, а текущая палитра видна на большом герое.
Статические PNG загружаются до меню; отдельных живых актёров на плитки нет.

Воспроизведение в свёрнутом нефокусируемом окне:

```sh
godot --path . --windowed --position -20000,-20000 --log-file /tmp/sfery-editor-thumbnails.log -s res://tools/avatars/build_editor_thumbnails.gd
```

После генерации выполнить обычный импорт проекта. Скрипт использует
tools/test_window.gd и не поднимает окно поверх рабочего стола.
