# Локальные клипы Kevin Iglesias FREE

Выбранные пользователем движения: `CastDirect` — короткий выпад правой рукой с картой перед собой,
`Boomerang` — боковой бросок карты ворот, `BallThrow` — бросок сферы всем телом.
Мужские и женские варианты перенесены на обе VRM-основы.
CastDirect берётся из готового Direct1H01_R; альтернативный CastCall остаётся
левосторонним материалом сравнения и в выбранной игровой активации не используется.
Игровой старт пропускает CastingEnter; короткий выход сразу, ignition .22с.
Astra medium добавила согласованную постановку плеча/локтя/кисти для показа
настоящего лица карты вперёд, удержание до1.75с и плавный возврат до2.80с.
Карта жёстко следует рассчитанному Right хвату, свободная левая рука опущена. Кости/rest/bind исходников
не меняются. Готовый клип управляет телом и запястьями; удержание плоской карты
адаптируется отдельно по поверхности пальцев каждого костюма при подготовке профиля.
`ObjectGrip` сохранён для сравнения, в игровом хвате сейчас не используется.

Источники: [Throwing FREE](https://kevdev.itch.io/human-throwing-animations-free),
[Spellcasting FREE](https://kevdev.itch.io/human-spellcasting-animations-free).
URL, ID Godot/Unreal архивов и SHA256 закреплены в `tools/avatars/kevin_sources.json`.

Оригинальные архивы, JSON-сэмплы и готовые `.res` остаются в игнорируемых каталогах.
В игру попадают только подготовленные ресурсы как часть конечного продукта.

Подготовка из корня проекта:

```bash
python tools/avatars/fetch_kevin.py
ALSOFT_DRIVERS=null SDL_AUDIODRIVER=dummy blender --background -noaudio --factory-startup --python-exit-code 1 --python tools/avatars/export_kevin_motion.py
godot --headless --path . -s res://tools/avatars/retarget_kevin.gd
python tools/check.py --profile presentation --checks import motion-bank vrm-fighter
```

`fetch_kevin.py --verify` сверяет локальные архивы без сети. Экспорт работает фоном,
не управляет открытым Blender. JSON и две библиотеки создаются в `kevin_local/`.
После создания полезно сохранить локальные SHA256 библиотек вместе со сборкой.
На Boot `VrmFighter.apply_profile()` загружает их в статический кэш до меню;
в матче нет импорта FBX/VRM или переноса анимации. Для экспорта они должны быть
установлены локально. При отсутствии или неполном наборе работает CC0 Quaternius;
его внешний вид не равнозначен новому варианту. Необязательный `motion-bank`
явно отмечается SKIP в профиле без банка; отдельный запрос этой проверки — ошибка.

Сфера теперь видимого диаметра 9 см и сохраняет размер в руке/полёте. Для стабильной
физики существующий контактный объём радиуса .35 м пока сохранён; это не проверка
столкновений девятисантиметрового тела. Реальная остановка и поворот оболочки
по-прежнему сохраняются. Карта ворот держится правой рукой до выпуска, летит с
постоянным размером по дуге с вращением и растёт только на поле.

Ворота после роста получают физическую верхнюю поверхность на .052м, качение
и видимая оболочка учитывают эту высоту. В полёте/руке/лотке поверхность отключена.
