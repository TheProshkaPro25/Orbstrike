# Костюмы BOOTH

- `haori_0.res`: [羽織のある着物 — siroihakumai](https://booth.pm/en/items/6848282), для Сакурады. Прочитаны пять исходных текстур и пять слоёв геометрии из `kimono.xwear`. Сохранили 20 360 треугольников, UV и прозрачность рисунка; геометрию подогнали к суставам и расслабленной позе Сакурады. Автор разрешает переделку и распространение производных, атрибуция необязательна. Кимоно происходит из стандартного костюма VRoid, к которому автор добавил хаори и ханэри. В архиве нет отдельного ограничения. Действуют [условия pixiv для работ, созданных в VRoid Studio](https://vroid.pixiv.help/hc/en-us/articles/4405813333657-Can-I-use-the-models-created-with-VRoid-Studio-Stable-Ver-for-commercial-purposes); редактор игры сохраняет настройки внешности в JSON, без экспорта модели.
- `operator_1.res`: [Silver’s Operator Coat — Picklebarrel3D](https://booth.pm/en/items/5485010), для Виты. Прочитаны 17 811 треугольников из авторского `.blend`, исходные UV, цвет, нормали OpenGL и AO. Игровые текстуры подготовлены в 2048/1024/1024 пикселей и сжаты заранее; PBR-материал автора адаптирован к шейдеру MToon. Брюки, обувь и простой внутренний слой добавлены из деталей клиента. Автор разрешает переделку и коммерческое использование с атрибуцией, бесплатное включение в составе пакета без отдельного распространения ассета. Архив, FBX, Blender, PNG и Substance Painter исходники остаются локальными. `Readme_Substance.zip` только указывает, где скачать необязательный проект Substance Painter.

Эти костюмы используют готовый `Skin` своей модели и существующие анимации. Пружины и физика ткани из исходников не перенесены. Косточки рукавов и ремешков следуют ближайшим соответствующим суставам. У закрытого подола кимоно заметно растяжение при широком движении ног в завершении броска. У пальто оператора веса каждой полы плавно переходят от таза к своему бедру, поэтому в широком шаге брюки не прорезают стёганую панель.

Воспроизведение из корня проекта (Godot, Blender, Python с NumPy и Pillow; оба архива скачиваются со страниц авторов):

```sh
godot --headless --path . -s res://tools/avatars/build_booth_outfits.gd -- --targets
python tools/avatars/prepare_booth_geometry.py build/wardrobe-nov12/targets.json /path/to/kimono.xwear /path/to/Silver_s_Coat.zip "$PWD/build/wardrobe-nov12/input"
godot --headless --path . -s res://tools/avatars/build_booth_outfits.gd
```

Обработка проверяет SHA-256 исходных архивов. Формат бинарной геометрии XWear v2 сверили по [публичному генератору froz3ncore](https://github.com/froz3ncore/VRoid-Character-MCP/blob/b02b108ab4a8b4333ecf206a199a7a0403aa7ffe/pipeline/blender-addons/vroid_xwear_direct/__init__.py). В клиенте нет этого инструмента, Blender, VRoid Studio и обработки архивов.

Пресеты и геометрия VRoid подчиняются [условиям pixiv](https://vroid.com/en/studio/guidelines). В редакторе выбираются подготовленные игровые ресурсы. Сохранение записывает ID и параметры в профиль, а исходные архивы, доноры и отдельный экспорт одежды в клиент не включаются.

Для повторной подготовки в VRoid Studio 2.16.0 открыть готовые `.vroid` мантии и формы OC. Остальные предметы надеть через вкладку Outfit на временную основу того пола, к которому они относятся. Шлем Orchid лежит в категории дополнительной пряди. Для его экспорта снять прочие волосы временного донора. Экспортировать в VRM без уменьшения материалов и сетки. Для женских версий жакета и Dreamy использованы `jacket_pants_vita.vrm` и `dreamy_angel_vita.vrm`, с ключами `jacket_pants` и `dreamy_angel`. Для остальных имена VRM совпадают с именами ресурсов в таблице без суффикса основы, например `dirndl.vrm`.

```sh
python tools/avatars/stage_booth_vrm.py build/wardrobe-nov12/export assets/avatars/_booth_import_work
godot --headless --max-fps 60 --path . --editor --import
godot --headless --max-fps 60 --path . -s res://tools/avatars/build_booth_vrm.gd -- res://assets/avatars/_booth_import_work/dirndl.vrm dirndl "$PWD/assets/avatars/booth/dirndl_1.res"
```

После конвертации переместить временную папку импорта обратно в `build/`. Конвертер сохраняет UV и треугольники одежды, перепривязывает суставы к существующей основе, локализует текстуры и удаляет закрытые участки кожи из варианта одежды. Лицо, кости и выбор причёски исходного персонажа сохраняются. Для новых комплектов Виты, экспортированных через Studio, сценическая раскраска тела заменена нейтральным атласом её другого игрового образа, а в форму OC перенесён рисунок авторских чёрных чулок.

На мантии четыре дополнительных треугольника из существующих вершин закрывают
стык под левым рукавом в «Победе». Нижний слой укорочен и заужен внутри
голенищ. При широком броске остаётся растяжение закрытого подола.

## Состав Orbstrike 0.4.3

В публичных исходниках доступны шесть дополнительных костюмов: кимоно с хаори,
хаори с оленями, доспех, мундир, форма OC и жакет с брюками.
Фэнтезийная мантия, пальто оператора и Dreamy Angel добавляются только
при сборке готовой бесплатной игры. Атрибуция включена в ZIP.
Дирндль остаётся в локальном каталоге: английская лицензия отдельно
ограничивает передачу самих изменённых данных, а игровой PCK содержит
извлекаемый подготовленный ресурс. В сборке 24 костюма, в чистом открытом
проекте 21, в полном локальном каталоге 25.
