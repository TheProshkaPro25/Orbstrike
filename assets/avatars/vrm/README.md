# Готовая аниме-основа редактора

В основном «Мой персонаж» используются две основы pixiv: Sakurada Fumiriya и Vita.
Из пяти CC0-источников подготовлены независимые детали:
- семь причёсок для каждой основы: исходная, острые пряди, хвосты с ушками,
  боб, причёска второй основы, новые взъерошенные и асимметричная чёлка;
- четыре мужских костюма: школьный, худи, короткое худи, удлинённая куртка;
- пять женских: сценический, платье-рубашка, летнее платье, короткое худи, удлинённая куртка.

Доступны формы глаз/бровей/рта на исходных авторских морфах, цвета волос и глаз,
тон кожи, палитра одежды, рост, выражения и свет для просмотра. Образ сохраняется
в JSON v2. Профиль v1 переносится в памяти с сохранением имени/прежних полей;
до сохранения исходный файл не меняется, при сохранении копируется в .bak.

## Подготовка и проверка

```bash
python tools/avatars/fetch_vrm_sources.py --verify
python tools/avatars/build_palette_shaders.py
python tools/check.py --profile presentation --checks import
XDG_CONFIG_HOME="$PWD/build/vrm-source/config" XDG_DATA_HOME="$PWD/build/vrm-source/data" godot --headless --path . --log-file "$PWD/build/vrm-source/parts-build.log" -s res://tools/avatars/prepare_vrm_parts.gd
python tools/check.py --profile presentation --checks vrm-fighter vrm-parts character-editor
```

Для восстановления недостающих источников уберите --verify. Подготовка деталей
выполняется заранее: CPU skinning в позу редактора, перевод волос в пространство
Head, подгонка по размерам лица, подгонка тела по росту, объединение поверхностей
по материалам. Волосы следуют за Head; у тела сохранены веса, кости сопоставлены
по humanoid-именам (донорские дополнительные — по ближайшему общему предку).
Для каждой основы подготовлен Skin с обратными матрицами расслабленной позы.
Исходные VRM/rig не меняются. Сжатые ArrayMesh
в parts/ не содержат дубликатов текстур: metadata ссылаются на оригинальные
материалы по source ID/имени. Проверенный manifest содержит SHA файлов/источников.

В игре используются готовые PackedScene/ArrayMesh. StartupCatalog прогревает обе
основы, все причёски/костюмы до меню. После меню нет сети/парсинга VRM/запекания
мешей. VrmParts кэширует только ресурсы материалов, без живых Node. Материалы
каждого актёра отдельные, геометрия/текстуры общие. При быстрых сменах материалы
удерживаются до завершения кадра.

VrmFighter использует те же детали и готовые полнотелые клипы Quaternius
(подготовка и лицензии — ../motions/README.md):
ожидание, бросок, команда, открытие ворот, победа, поражение.
Для действий перенесены 52 кости, включая таз/ноги/пальцы; мимика A/I/O отдельная. GameLoading готовит по два экземпляра
каждой основы до меню. Матч берёт нужные готовые узлы, применяет актуальный профиль
и возвращает их после завершения. Портреты — отдельные камеры на тех же актёрах,
изолированные слоями. Камера показывает бойца при броске, способности и открытии ворот, затем
возвращается к полю. Сфера выпускается из кисти; скорость рассчитывается
ShotPhysics из этой точки. Размер оболочки в руке уменьшен до .075 м радиуса,
при переходе к погоне восстанавливается аренный масштаб. Озвучки пока нет.
Ходьба, полная библиотека движений, сжатие текстур и замеры памяти ещё впереди.
Secondary motion отключена: исходный solver не поддерживает масштабированные
персонажи корректно; волосы жёстко следуют за Head.
Тесты всегда свёрнуты/нефокусируемы штатным wrapper. LegacyCharacterEditor и
VrmPreview сохранены для сравнения/проверок; обычное меню открывает CharacterEditor.


Для мужского hoodie hand/finger-влияния подготовленной геометрии дополнительно
согласованы с пивотами целевой основы (исходный donor имеет другие пропорции кисти).
Узкое воспроизведение только этой детали:
`godot --headless --path . -s res://tools/avatars/prepare_vrm_parts.gd -- --only-hoodie-hands`.
Это пересоздаёт body_0_1.res, не меняя исходныеVRM, skin/rest/bind/UV и остальные части.
Флаг и исправление входят в тот же генератор; SHA записан в parts/manifest.json.


## Производные фасоны и причёски — 2026-11-01

Новые ID добавлены в конец: style5/6 для обеих моделей, male clothes2/3,
female clothes3/4. Профиль остаётсяv2, старые ID/файлы не переставлялись.
Это производные существующих CC0-частей, а не отдельные модели с нуля:
форма макушки/чёлки изменена по вершинам; у худи изменены длина/объём/горловина,
добавлены воротник и застёжка, сохранены источник фактуры складок и UV.
Короткий вариант честно называется «Короткое худи»; длинный — городская куртка.
Второй фасон без наружного пояса. Основы/кисти/риг/rest/bind/исходные5VRM не менялись.

Женский вариант одежды подогнан с donor-худи на целевой rig, использует свою
голову/кисти/skin; треугольники тела под закрытой одеждой скрыты в новых частях.
В новых мешах сохраняются веса и UV, normals/tangents пересчитаны по деформации.
Кастомные материалы хранятся как ресурсы в metadata; оригинальный skin-материал
разрешается по surface_sources, без дублирования исходных текстур. Общая
wardrobe_cloth.res обслуживает четыре новых костюма, палитра работает как прежде.

Воспроизведение только новых частей после основной подготовки:

```bash
godot --headless --path . --log-file /tmp/wardrobe-build.log -s res://tools/avatars/build_wardrobe_variants.gd
python tools/avatars/wardrobe_manifest.py --record
python tools/avatars/wardrobe_manifest.py
python tools/check.py --profile presentation --checks vrm-fighter vrm-parts character-editor
```

Без --record manifest-скрипт только проверяет SHA исходных VRM, прежних подготовленных
частей, новых ресурсов и генераторов. Девять ресурсов:4hair+4body+1texture.
Основной parts/manifest.json не переписывается, новый — wardrobe_manifest.json.
StartupCatalog прогревает7причёсок и4/5костюмов до меню; в игре нет генерации
геометрии/новых загрузок VRM. Волосы как прежде жёстко следуют Head; cloth-симуляция
новым курткам не добавлялась. Художественная приёмка автором отдельно от тестов.


## Исправление посадки рукавов — 2026-11-01

Одного переноса hand/finger-пивотов оказалось недостаточно: рукава оставались
на donor-оси, кисти выходили через бок. CPU-подготовка теперь согласует оба конца
UpperArm/LowerArm с целевыми суставами (включая длину сегмента) и Hand-влияния
ткани с запястьем. Кожа предплечья следует той же оси; пальцевые пивоты прежние.
В производных фасонах сохранена кожа LowerArm под рукавом, чтобы сгиб не открывал
обрезанный край. Это исправление изменяет прежний body_0_1.res и четыре новых
костюма; исходные VRM, Skin-ресурсы, rest/bind/UV, волосы и другие части прежние.
Основной manifest обновлён для body_0_1 и генератора; затем wardrobe_manifest.

Воспроизведение: сначала команда --only-hoodie-hands выше, затем генератор
производных фасонов. Контроль: `python tools/check.py --profile presentation
--checks wardrobe-wrists vrm-fighter` (одной строкой). Кадры/сравнение находятся
в build/checks/wardrobe-wrists; проверяются реальные skinned-сечения манжет,
а не только положения костей. Новая подгонка выполняется офлайн.
