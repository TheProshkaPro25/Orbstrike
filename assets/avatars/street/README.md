# Первый уличный образ

Бомбер, высокий хвост и съёмный футляр для трёх сфер под обе прежние основы.
Это первый контрольный образ из плана редактора, не весь запланированный гардероб.

Бомбер производен от подготовленных CC0 body_0_2/body_1_3: сохранены манжеты,
кисти, UV и веса прежних частей; в новой копии изменён объём торса, удалены
острова капюшона/шнурков, добавлены воротник, пояс и карманы. Хвост использует
CC0 hair_0_0/hair_1_0, новые пряди и подложку по поверхности целевой головы.
Футляр создан процедурно и жёстко взвешен на Hips. Исходные VRM/parts не меняются.
Происхождение прежних основ: ../vrm/README.md. Новых сторонних загрузок нет.

В редакторе есть кнопка «Уличный образ». Новые ID дописаны в конец: волосы 9,
бомбер 5/6. Поле vrm_case (0/1, по умолчанию 0) добавлено совместимо в профиль v2.
Футляр показывается только с бомбером; выбор запоминается при смене одежды.
Волосы следуют Head без новой физики. Все ресурсы готовятся и прогреваются до меню.

Воспроизведение из корня проекта:

```sh
godot --headless --path . --log-file /tmp/street-generation.log -s res://tools/avatars/build_street_set.gd
python tools/avatars/verify_street_set.py
python tools/check.py --profile presentation --checks street-set character-editor
```

После намеренного изменения генератора записывать manifest через `--record`
только после проверки. Графические тесты используют свёрнутый нефокусируемый
wrapper; новые кадры находятся в build/checks/street-set/.
