# Спортивный образ

Спортивная куртка со стойкой и застёжкой, зауженные брюки, двойные светлые
лампасы и короткая слоистая причёска с боковым пробором — для обеих прежних основ.
Новые ID дописаны в конец: причёска 10, костюм 6/7. Прежние ID не переставлены.
Джинсовая расцветка к спортивным брюкам не применяется, прежний выбор запоминается.
Съёмный футляр по-прежнему относится к бомберу.

## Происхождение

Это производные уже находящихся в проекте конкретных CC0-образцов pixiv,
без новых загрузок. Точные исходные URL, SHA и embedded metadata: `../vrm/README.md`,
`../vrm/*.source.json`, `tools/avatars/vrm_sources.json`.

- Куртка/брюки: копии `body_0_2.res` и `body_1_3.res`, производные от
  HairSample_Male с уже принятыми подгонкой, кистями и весами целевых основ.
  В новых копиях сужен торс, удалены острова капюшона/шнурков, заужены штанины.
  Добавлены стойка с перекрытием края куртки, застёжка и карманы. Лампасы вырезаны
  из действительных треугольников ткани с интерполяцией весов; они следуют рукавам
  и брюкам. Позиции/UV/веса кистей, открытой кожи и обуви сохранены. Закрытая воротником
  полоса кожи плеч/шеи скрыта только в новой копии: край отсечён точно, новые
  вершины интерполируют UV, normals/tangents и веса без зубчатого среза.
- Причёска ID10 производна от полноценных слоистых волос HairSample_Male:
  `hair_0_2.res` / `hair_1_2.res`, ранее подогнанных к обеим основам.
  Сохранены авторские пряди, их индексы и UV; чёлка укорочена и смещена вбок,
  концы у висков/затылка короче, тонкая верхняя прядь приглушена. После деформации
  пересчитаны нормали/касательные. Это производный вариант имеющихся CC0-волос.
- Под настоящими прядями добавлен вспомогательный слой коротких корней сзади и
  у висков, закрывающий открытую область донора. Он следует наружной поверхности
  целевой головы и скальпов принятых костюмов. Его передний край поднят под чёлку;
  отдельной полосы на лбу нет. Задняя подложка выглядит более гладкой, чем внешние
  авторские пряди. Волосы жёстко следуют Head, новая физика не добавлялась.
- Текстура только этих новых волос локально осветлена с сохранением авторской
  фактуры и alpha внешних прядей: естественный вариант тёплый каштановый,
  прежняя палитра может показывать и светлые цвета. Для внутреннего слоя alpha
  заполнена. Обе производные текстуры встроены в два новых `.res`; исходная
  текстура и общие шейдеры палитры не меняются.
- Материалы используют существующий MToon; фактура куртки взята из уже принятого
  `wardrobe_cloth.res`. Контрастная отделка имеет отдельную поверхность. Поддержана
  прежняя палитра верха и волос через `VrmParts.material_for`.

Исходные VRM/GLB, прежние parts, skeleton/rest/bind/UV и creature-модели не меняются.
Новые ресурсы готовятся заранее; в матче нет генерации или загрузки исходного VRM.

## Воспроизведение

Из корня проекта:

```sh
godot --headless --path . --log-file /tmp/sport-generation.log -s res://tools/avatars/build_sport_set.gd
python tools/avatars/verify_sport_set.py
python tools/check.py --profile presentation --checks sport-set
```

Для замены только волос, сохраняя оба принятых костюма побитово:

```sh
godot --headless --path . --log-file /tmp/sport-hair-generation.log -s res://tools/avatars/build_sport_set.gd -- --hair-only
```

Финальная замена волос от 2 ноября проверялась отдельным целевым стендом
`build/checks/sport-hair-review.gd` через тот же свёрнутый нефокусируемый wrapper:
обе основы, исходный/спортивный костюмы, фронт/три четверти/бок/затылок,
естественный/серебристый цвет и крайние росты. Кадры —
`build/checks/sport-hair-review/candidate_0.png` и `candidate_1.png`.
Это проверка волос; широкий тест манжет и одежды для неё не повторялся.
По правилу автора тестовые задачи выполняет Terra.

`manifest.json` содержит SHA256 прямых входов генератора и четырёх новых ресурсов.
После намеренного изменения генератора записывать его с `--record` только после
просмотра новых кадров. Графическая проверка использует штатный свёрнутый,
нефокусируемый wrapper; кадры находятся в `build/checks/sport-set/`.
Геометрия проверяется отдельно от полного матча и Windows-сборки.
