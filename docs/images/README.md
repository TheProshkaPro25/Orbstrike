# Скриншоты для страницы игры

Это реальные кадры игры, без дорисовки и изменения композиции.
`menu.webp` — главное меню из проверенного клиентского PCK 0.4.1.
`canyon.webp` и `harbor.webp` — принятые кадры финального стенда локаций
от 5 ноября 2026, соответствующие окружениям 0.4.1; в стенде скрыт игровой HUD.
Исходные PNG сохранены локально в build/, происхождение и SHA256 — в provenance.json.
Для страницы GitHub кадры перекодированы в WebP 1280×720, качество 91.

Тестовые игровые запуски ради оформления не выполнялись.
