# Уточнённые замечания к боевому UI — 8 ноября 2026

Автор уточнил: «в бою иногда подсказки у карт зависают, кнопка выйти из турнира до сих пор наезжает на другие». Работа возобновлена после прежней остановки. Исправлены два воспроизводимых пути; авторская приёмка пока не получена.

`battle-ui-followup` использует настоящие CardView/CardHover, BattleHud, HudUI и фабрику/позиционирование турнирной кнопки Main. Без Boot, моделей и сохранений. Исходный прогон: **58 проверок,14ошибок** ([before.log](before.log)): пересечение турнирного выхода с левой плашкой/журналом и боевыми панелями, удержание клавиатурного раскрытия после перехода к указателю вне карты и немедленное возвращение подсказки сыгранной карты после Esc.

- CardHover закрывается при движении или кнопке мыши во всём viewport. Раньше раскрытие ждало только локального mouse_exited, который не приходил, если фокус восстановили при перестройке руки, когда указатель уже находился вне карты.
- BattleHud закрывает раскрытие по Esc и подавляет его повторное появление на той же плашке до нового наведения или нового клавиатурного фокуса. Полный текст остаётся доступным при следующем наведении. Событие отмены не поглощается этим обработчиком.
- Турнирный выход использует общий с дуэлью слот: справа вне боя, по центру верхней полосы в бою. Смена стиля/фазы и resize сохраняют привязку. Верхний отступ4px оставляет42px кнопку выше подписи фазы на52px; прежний фиксированный(12,74) удалён. В фабрике задано безопасное начальное положение ещё до добавления в UI.

Первая промежуточная позиция через старый дуэльный слот дала58/4: пересечение подписи фазы в классике и правой боевой панели в приборном стиле. Эта позиция не принята; исправлен общий слот в бою.
