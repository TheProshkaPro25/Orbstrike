## Нормализация и пределы

CPU-кадры используют один source frame, включая все хранящиеся POSITION, без
подгонки к новому силуэту. Bounds всех сохранённых accessor одинаковы: mirror
`CreatureModels.build` даёт scale11.943996311305137 и прежний центр. Bounds только
активных tri становятся меньше: mirror scale15.045182326978336, отношение
1.259643919408941. Реальный Godot importer может сохранить либо уплотнить
неиспользуемые вершины; перед promotion нужно измерить imported AABB и реальную
нормализацию. Эти данные нельзя выдавать за нулевую runtime-разницу масштаба.

Идентичные оставшиеся tri/attributes/skeleton/binds/clips математически сохраняют
их skin surface при тех же bone matrices. Это не проверка фактического
runtime/support/анимации. Godot import, GPU, движение, матч, звук, Windows,
сервер, сборка и публикация этим кандидатом не выполнялись. Решение о promotion
принимает родительский этап после независимой проверки.
