# Новое меню карьеры — 8 ноября 2026

По поручению автора переработан клиентский `CareerPanel`: вместо длинных списков
правил — самостоятельные визуальные действия в существующей золотой/электронной теме.

- Первый шаг: шесть стихий с символами и живым предпросмотром стартовой тройки;
  три явные кнопки сложности с короткими объяснениями.
- Команда: три портрета, сила, XP-полосы, боевой уровень и кнопка удаления прямо
  под каждым участником; свободные места и отдельная коллекция замен. При 960×540
  все три управляющих ряда видны без прокрутки. Общий G/лимит также в footer.
- Колода: три слота ворот или способностей, арт, краткий эффект, отдельные действия
  «Заменить» и «Условия». Выбор — из совместимых купленных карт; полные условия
  сохраняются в прокручиваемом окне, в том числе поверх окна выбора.
- Магазин: сетка предметов с портретами/артом, три категории, цена, владение,
  нехватка кредитов и условия открытия. Новые доступные предметы идут первыми;
  покупки во время кубка остаются закрытыми по прежним правилам.
- Путь: три карточки лиг, текущая/пройденная/доступная следующая лига, лимиты и
  краткие награды. Подробная справка всегда доступна сверху и отдельно из наград.
- Главные действия создания, старта, продолжения, повтора и следующей лиги
  остаются в постоянном нижнем блоке.

Vulkan 1.4 / Forward+, штатный wrapper `tools/test_window.gd`, свёрнуто,
нефокусируемо, offscreen, 60 FPS. Изолированные настройки/сохранение; пользовательский
профиль не затрагивается. Стенд отдельно готовит PNG-портреты, как Boot;
production UI только получает уже подготовленные ресурсы, без GLB/setup.

Проверены 960×540/1280×720, обе темы, реальные mouse events для стихий/сложности,
категорий магазина и выбора карты, сигналы регистрации, неполная/закреплённая тройка,
покупка/защита от повторной покупки, вложенная справка, завершённый кубок и следующая
регистрация. Для проверки действительной замены куплена вторая синяя карта:
реальный scroll+click меняет «Искру» на «Жаркий натиск», новый id проверен в
`_picks` и сигнале регистрации. Завершение кубка — явно заданные результаты
фикстуры, не физические матчи.

Sol лично просмотрел все 20 финальных PNG; после последних изменений повторно
просмотрены затронутые кадры магазина/лимита/доступной лиги/новой карты. Копии шести
основных кадров здесь; весь набор в `build/checks/presentation/selected-career-ui/career-ui/`.
SHA256 всех 20 — `png-sha256.json`. Независимый Sol просмотрел код/правила и 16 PNG;
его замечания о фактической замене и надписи следующей лиги исправлены.

Начальная попытка выявила GDScript type inference (`cleared: bool`), её лог сохранён.
