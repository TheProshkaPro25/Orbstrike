# Delta appearance и интро локаций — 8 ноября 2026

По новому поручению автора выполнен локальный перенос шести appearance/open VFX
из соседней Delta (`codex/delta-visual`, принятый этап `814096c`) и представление
локации до появления интерфейса. Это изменения исходников после опубликованной0.4.2.6.
Новый пакет и выпуск не создавались.

## Изменения

- Пламя: мелкие искры из объёма фигуры; Буря: мягкие клубы наружу; Свет: золотые
  блёстки, столб strength0.35 и одиночный flash alpha0.10; Камень: неровные
  восьмигранные обломки; Тень: тёмные клубы с фиолетовой кромкой; Прилив: синие
  объёмные капли. Материалы, текстуры и меши кэшируются. Бюджеты HIGH/MED/LOW
  сохранены, lifetime0.9. Дополнительных моделей/светильников не добавлено.
- Исправление alpha аддитивных частиц ограничено новым `open_add`.
  Прежние trail/roll/burst материалы, атаки, освещение арены и ring_wave не копировались.
  Из VisualUtil перенесён только strength light_pillar. Общий синхронный
  ArenaDirector.open_creature вызывают раскрытие при посадке, прибытии в бой и замена;
  повтор уже открытого Света не даёт второй экранный импульс.
- LocationIntro показывает три индивидуальных движущихся ракурса каждой арены,
  всего7.2с реального времени. Название по центру, кинополосы, кнопка «Пропустить».
  Камера Святилища остаётся внутри ротонды. Reduce motion: неподвижный обзор1.8с.
  До завершения `_preparing` остаётся true, MatchController не стартует и реальные
  элементы интерфейса скрыты; затем возвращается обзор и прежнее появление HUD.
- Boot/каталог98/аренда, hold_landing_pose, исходные49GLB/rest/bind/UV/анимации,
  core/PowerCalc/правила и сервер не изменялись.
