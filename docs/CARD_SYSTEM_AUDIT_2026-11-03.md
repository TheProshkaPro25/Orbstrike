| Код | Решение и доказательство |
|---|---|
| CARD-15 | Отмена зависит от действующего источника. Тишь → Брызги → чужая Хватка даёт 460:360, Брызги сохраняются; Тишь → Хватка по-прежнему позволяет отменить саму Тишь. Устойчивое разрешение учитывает источники и действующие цели; подавленное позднее прикрепление не отвлекает реакцию от активного раннего |
| CARD-16 | HARD исключает публичный использованный ID, а не весь класс. Вероятностная модель учитывает старт по одному классу, добор без повторов и публичный размер руки. После одной захваченной бронзы риск следующих ловушек не обнуляется. Скрытые ID в решении не читаются |

| CARD-18 | Копия наследует запрет дальнейших своих карт от действующего скопированного эффекта Колец/Сброса. Отмена самой Копии убирает эффект и запрет; неотменяемость оригинала не защищает Копию |
| CARD-19 | На лице всех карт — выразительная рамка/стихия, роль, числовой эффект, ключевое ограничение и короткая сводка. Полные условия доступны в 15 px hover. Эмблема уменьшена ради читаемости; эффект минимум 10 px. При ширине96 длинный заголовок сокращён с многоточием, полное имя остаётся в hover |
| CARD-20 | По одной равной красной ответной отмене каждой стихии; общие проверки цели/запретов PowerCalc используются контроллером и ИИ. Сервер проверяет ту же допустимость и передаёт одинаковую отмену обоим клиентам |
| CARD-21 | Проверены цепи контротмен, sure/слияния, цена слота/действия, защита ворот от подавления, контрответ и локальные сравнения Поля/Алтаря/ворот вида; выполнены 24 парных матча ядра |

Шесть новых карт: **Пламя разрыва, Встречный ветер, Свет развеивания,
Каменная печать, Разрыв тени, Обратная волна**. `effect=negate`, `reactive=true`,
`moment=battle`, `lock` своей стихии, без прибавки силы. ID Бури —
`ability_gale_rebuttal`: прежний `ability_gale_counter` остаётся синим «Встречным вихрем».

Только в свой ответ в бою и при наличии цели: последняя уже действующая основная
карта соперника, кроме мгновенных/неотменяемых/слияний напрямую. Отмена основы
гасит слияние. Нет ожидания будущей карты. Саму реакцию можно отменить другой
реакцией или Хваткой. Расходует одно из трёх действий и обычный отдых. Реакция
занимает красный стартовый слот вместо сильной стихийной способности; присутствует
в обычном выборе и совместимом доборе. Авторские пресеты принудительно не заменены.

Реакция разрешена при запрете Тиши только когда её целью будет именно активная
Тишь. Глухие врата и собственный lockout не обходятся. Восстановление Тиши после
контротмены гасит позднюю силу выполненного Сдвига; обмен воротами сохраняется.
Эта законная цепь отдельно проверена контроллером и независимым runtime probe.
